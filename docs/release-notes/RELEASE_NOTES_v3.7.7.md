# CalcBook V3.7.7 发布说明（内测）

> 本版本仅供内测，不上传 Gitee / GitHub。

## 新增 / 调整

### 1. 截图窗口样式优化（对照成熟截图工具）
- **信息条贴选区上沿**：显示「宽 × 高 + 操作提示」，选区贴近屏幕顶部时自动
  画进**选区内部顶端**，不再飘到屏幕边缘和选区脱节；
- **按钮条贴选区右下角**：`确认截图 / 矩形 / 椭圆 / 重新选择 / 取消`，
  紧凑深色小按钮、确认键蓝色高亮；
- 选区放不下时按钮条自动贴进选区内侧，始终不出屏。

### 2. 默认列重排（老工程自动迁移一次）
- 新默认列（从左到右）：**序号 / 清单编号 / 项目名称 / 计量单位 / 计算公式 /
  工程量 / 图纸编号 / 图纸 / 备注 / 不计**；
- 「编号」→ **清单编号**、「单位」→ **计量单位**（只改显示名，数据 key 不变）；
- 「大样图来源」列取消（单元格里填过的内容仍存在工程文件中，不丢）；
- **工程量**是公式计算的结果列，放在计算公式后面；
- 老工程打开时**自动按新顺序重排一次**（存迁移标记，之后你自己拖动的列序
  不再被覆盖）；**每列已调好的宽度原样保留**；自定义列排在内置列后面。

### 3. 插入明细子目取消链接
- 右键「插入明细子目」**不再弹链接输入框**，直接建好就能填；
- 右键「设置链接…」保留：个别节点确要挂网址 / 文件路径时随时可设。
