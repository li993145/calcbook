# 工程量计算书 V2.9.0 更新说明

发布日期：2026-11-22

## 本次更新内容

1. **新增「导入表格文件」功能**
   功能区「计算书编辑 → 计算」组新增「导入表格」按钮，支持从
   `.xlsx`（Excel 工作簿）、`.csv`（逗号分隔）、`.txt`（制表符分隔）文件把数据导入当前分部。

## 导入对话框操作说明

1. **选择表格文件**：点「浏览」选择文件，对话框自动读取并预览。
2. **工作表与读取范围**：
   - xlsx 文件可在「工作表」下拉里选要导入哪张表；
   - 勾选「首行是表头」后，会按表头名自动对应字段；
   - 「数据起始行」指定源文件从第几行开始是数据（默认第 2 行，即跳过表头）。
3. **预览**：表格里显示源文件前 100 行内容，确认选对文件和范围。
4. **选择字段（列）并指定写入位置（列）**：
   - 每个源列一行：勾选「导入」→ 在下拉里选该列写入计算书的哪个字段
     （编号 / 项目名称 / 部位 / 计算公式 / 单位 / 备注 / 不计 / 自定义列）；
   - 有表头时自动按表头名对应，没有表头按位置顺延，都可手动改；
   - 「工程量」列由公式计算得出，不作为导入目标（源文件里的工程量列默认跳过）；
   - 同一字段不允许被两列同时写入，软件会拦截提醒。
5. **写入位置（行）**：
   - 「追加到末尾」：导入的数据接在当前分部最后一行后面；
   - 「从指定行开始写入」：填目标起始行号，从该行开始覆盖写入已有数据。
   - 行数不够时自动在末尾补足空行，数据完整落位。
6. 导入完成后自动重算公式、刷新表格，可用 Ctrl+Z 一键撤销整次导入。

## 兼容性说明

- `.csv` 自动识别 UTF-8 / GBK / UTF-16 编码，带引号的逗号单元格正确切分。
- 导入的内容进入撤销栈，Ctrl+Z 可整体撤销。
- 数据文件格式不变，V2.5 以后的工程文件可直接打开。
