# 工程量计算书 V2.7.3 更新说明

发布日期：2026-11-22

## 本次更新

1. **弹窗按钮全中文**：所有对话框里的 `OK` / `Cancel` 标准按钮统一显示为「确定」/「取消」，常见确认按钮也同步中文化。
2. **取消选中行高亮**：原「选中行高亮」功能在一些环境下仍不生效，本次先移除该按钮与绘制逻辑；「选中列高亮」继续保留并正常工作。
3. **打印图标改为打印机样式**：标题栏、功能区「打印 / 打印预览」和打印预览窗口的打印按钮，统一换成直观的打印机图标；查看公式、说明等非打印按钮改用文档图标区分。
4. **同步发布准备**：本版本开始同时准备 GitHub 与 Gitee 双平台发布，减少手动同步。
