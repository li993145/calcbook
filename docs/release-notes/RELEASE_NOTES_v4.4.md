# V4.4 发布说明

## 修掉：导航栏收起后再也回不来

- **现象**：把左侧导航栏收起后，再也点不回来——用户表现为「窗口最大化了，咋回去看导航窗」，整个屏幕只剩表格、没有项目结构树。
- **原因**：原来唯一的「展开导航」按钮藏在公式辅助栏顶部的快捷链接行里；而单位工程汇总视图会把整条公式辅助栏隐藏，按钮跟着一起消失，导航就再也回不去了。
- **现在**：
  - 工作区**左缘新增一条常驻窄条**，上面就是导航栏开关（展开时 `◀` 收起、收起后 `▶` 展开）。**任何视图、任何窗口大小都在同一个位置**，导航收起后随时能再打开。
  - Ribbon「计算书编辑 → 编辑」组新增 **「导航栏」** 按钮（可勾选，勾着＝显示导航栏）。
  - 收起 / 展开时状态栏会提示一句。

## 其它

- 版本号升到 **V4.4**。
- 导航栏开合状态与 Ribbon 按钮、窄条按钮三方同步，不会出现「按钮显示的是另一个状态」。
