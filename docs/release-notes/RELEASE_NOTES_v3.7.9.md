# 工程量计算书 V3.7.9 发布说明

## 1. 默认列改为 9 列（修复 V3.7.7 多出的列）

- 默认列从左到右：**序号 / 清单编号 / 项目名称 / 计量单位 / 工程量 / 计算公式 / 备注 / 图纸 / 不计**
- V3.7.7 默认列里的「图纸编号」列取消（按用户确认保留「项目名称」与「工程量」）
- **老工程打开时自动迁移一次**：按新顺序重排、图纸编号列从表中取消；每列已调好的**宽度原样保留**，迁移只做一次（存标记），之后自己拖动的列序不会被覆盖
- 图纸编号的数据仍保存在工程文件里，需要时表头右键「添加列」可随时加回

## 2. 分部独立列名（明细表单独设置列名）

- 修复：以前在某个分部里改列名，**整个项目的列名都跟着变**
- 现在：表头右键「重命名列」输入名称后，可选**「仅本分部」**或**「整个项目」**——算某一个清单的明细表时，可以单独把列叫别的名字，其他分部不受影响
- 列名覆盖随工程保存、复制节点一起带上；项目级列名仍然全局统一

## 3. 单元格之间的运算（明细表）

- 公式里可用 **`A行号`** 引用**本分部**内其他行的工程量：
  - `A12*0.35` —— 第 12 行工程量 × 0.35
  - `SUM(A1:A10)` —— 第 1～10 行工程量求和
  - 引用上面的行、下面的行都能算对（两遍求值）
- 右键菜单**「插入合计行（自动汇总本分部）」**：在本分部末尾加一行合计，工程量自动汇总自上一个合计行以来的普通行；合计行**加粗显示、不可手改**、不参与上级 XJ 汇总与报表分类汇总——**不会重复计数**

## 4. 导航栏名称行高收紧

- 项目结构树的行高从「字体高 + 6」收紧到「字体高 + 2」，与名称字体高度一致，列表更紧凑

## 5. 查看报表：分类汇总（支持正则）+ 打印预览

- 「查看报表」顶部新增**分类汇总**：按**清单编号 / 项目名称 / 计量单位 / 备注 / 图纸编号 / 自定义列**分组，每组小计工程量与条数，可展开查看组内明细行
- 分组条件支持**正则匹配**：
  - `^0304` —— 清单编码 0304 开头的归一组
  - `门窗` —— 项目名称含“门窗”的归一组
  - 正则带分组时取分组 1 作组名；不匹配的行归「(未匹配)」
- **「打印汇总预览…」**：汇总表按页面设置的纸张分页打印预览（含总计行）
