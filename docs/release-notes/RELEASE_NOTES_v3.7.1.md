# 工程量计算书 CalcBook V3.7.1

发布日期：2026-11-24

本版修掉五个使用中暴露的问题：填充柄虚线框错位、导航栏操作后撤销跳回根目录、
「用分部打新」结果在表格里看不见、长计算式打印被页边界切一半、
查看报表窗口偏小且范围不能选。

---

## 一、拖动填充柄的虚线框不再错位

- 选中单元格按住右下角蓝色小方块往下拉（自动序号）时，**蓝色虚线框正好罩住要填充的区域**。
- 原因：绘制虚线框时把「右下角相对左上角的距离」当成了「相对右边缘的增量」，
  宽高各多算了一整格，看上去就像虚框拉到了旁边的单元格。
- 顺带把**目标区铺了一层淡蓝底色**，一眼能看出将要填到哪里。

## 二、导航栏操作后撤销不再跳根目录

- 撤销栈里现在会记下**操作前选中的节点 id**。
- 在项目结构树上做完操作（新建 / 删除 / 打新 / 粘贴等）按 **Ctrl+Z**，
  会**回到操作前的那个节点**；以前一律跳到根目录，还得一层层点回去。
- **Ctrl+Y 恢复**时回到操作后的新节点（例如刚「用分部打新」出来的副本）。

## 三、「用分部打新」的结果真的落到表格里

- 打新后**自动切到新节点**，工作区表格同步显示新内容，状态栏报出
  「N 条计算式、M 个下级节点」。
- 树里没有选中节点时，以**表格当前所在的节点**为模板，按钮任何时候都能用。
- 顺带修掉一个小问题：没有上级节点时不再白占一步撤销记录。

## 四、打印时长计算式不再被切一半

- 原来 Qt 富文本会把**高过整页的表格行从页边界中间截断**，长计算式只印得上前半截。
- 现在打印前先量每一行的高度，超高的行**自动缩小字号**（9pt → 8 / 7 / 6.5 / 6 / 5.5 / 5pt），
  保证**整行完整落在一页里**；预览与实际打印用的是同一套逻辑，分页完全一致。
- 缩过字号的行数会在打印完成后的状态栏提示。

## 五、查看报表窗口大改

- **打开时自动放大到主界面编辑区（表格）的大小**，不用缩在角落里眯眼看。
- 顶部新增两个范围下拉：
  - **「计算书」**：全部计算书 / 指定某一本计算书；
  - **「层级」**：全部层级 / 只看「单项工程」层 / 只看「单位工程」层 / 只看「分部工程」层 / 只看「分项工程」层。
- 选某一层时按层汇总，每个节点列出「**本级 N 条 / 含下级 M 条**」和工程量合计，一眼看清各层汇总。
- **所有列都能拖动改宽度**（项目名称列原来被设成 Stretch，拖不动）。
- 每个单元格加了**浅灰虚线框**（自定义 delegate 绘制），行列边界清楚、不刺眼。
