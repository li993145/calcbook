# 工程量计算书 V3.5.0 发布说明

> WPS 式选区统计、Ctrl+滚轮缩放、筛选灵敏度修复。

## 本次改动

1. **右下角小计改为选区统计**
   - 状态栏右下角不再显示固定的分部小计。
   - 单选或多选「工程量」列数据时，实时显示 `求和=… 平均值=… 计数=…`；选中整行时会统计其中的工程量单元格；未选中工程量数据时该区为空。

2. **Ctrl + 鼠标滚轮缩放表格**
   - 在表格上按住 Ctrl 滚动滚轮，单元格字号与手动行高 / 列宽按同比例放大缩小（6–24 号字，1pt 步进），冻结镜像同步。
   - 不按 Ctrl 时滚轮照常滚动表格；缩放只影响当前显示，不写入工程文件 / 设置，重启恢复用户字体。

3. **修复筛选"不灵敏"**
   - 关键修复：筛选窗口里切换「筛选列」现在真正生效。此前始终使用打开窗口前的当前列，导致换列后没反应或隐藏错行。
   - 内容留空、正则写错会明确提示，不再"点了像没反应"。
   - 单元格编辑后筛选结果立即重算；颜色筛选列出当前分部所有列出现过的颜色。
   - 沿用 V3.4.1 的三个清除筛选入口：筛选窗口、工具栏、右键菜单。

## 兼容性

- `.gcls` 工程文件格式未变，旧工程可直接打开。
- 仅发布 Gitee，未提供 GitHub Release。
