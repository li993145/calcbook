# 工程量计算书 V2.8.1 更新说明

发布日期：2026-11-22

## 本次更新

1. **删除「写入公式」按钮**：移除「公式编辑」功能区里点了没反应的「写入公式」按钮；公式辅助输入框仍可正常使用，直接在单元格或辅助框输入公式即可。
2. **插入函数加入「求平均值」**：统计函数组新增 `avg`（如 `avg(1,2,3) = 2`），公式引擎同步支持，可在公式里直接写 `avg(...)`。
3. **取消 XJ 子分部汇总函数**：插入函数面板不再提供 `XJ()`，公式说明中的相关条目一并移除；已有工程文件里的旧 `XJ()` 公式仍可正常计算，历史数据不受影响。
4. **放大按钮加大**：分类汇总面板标题行的「放大 / 收起」小按钮尺寸由 20×20 加大到 26×26，更好点。
5. **打印区域移到右键菜单**：「设置打印区域 / 清除打印区域」从「数据输出」页移到工作区表格右键菜单——框选单元格后右键即可设置，操作更直观。快捷栏「打印选中区域」保留。
