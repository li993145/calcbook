# 工程量计算书 V2.10.0 更新说明

发布日期：2026-11-23

## 1. 复制粘贴完善

- Ctrl+C / 右键「复制选中单元格」改为**按选中区域**复制（矩形区域复制区域，
  原来是复制整行），可直接粘贴回计算书或 WPS / Excel
- Ctrl+X 剪切选中行；Ctrl+V 粘贴自动扩展行数（不变）

## 2. 拖动填充柄（自动序号，仿 WPS）

选中单元格（或矩形区域）后，右下角出现**蓝色小方块**，按住它**向下 / 向右拖动**：

- 纯数字：自动等差递增。选一个 `1` 拖出 `2、3、4…`；选 `1、3` 两格拖动会
  推断步长 2，填出 `5、7…`；选多个相同数字则原样复制
- 尾号数字：`A-001` → `A-002`、`TG102.103` → `TG102.104`、`深度3` → `深度4`，
  前导零和前后缀都保留
- 汉字 / 其它文本：循环复制；**公式列整体复制**（不会悄悄改公式里的常数）
- 向上 / 向左拖动：递减（`A-005` 往上拖出 `A-004`）
- 拖动过程有蓝色虚线预览框；整次填充 Ctrl+Z 一步撤销

## 3. 格式刷

选中源单元格 → 功能区「计算书编辑 → 格式刷」或右键菜单「格式刷」→
点击或拖选目标区域，把**字体 + 底色**一起刷过去；Esc 取消；可撤销。

## 4. 排序

右键「排序…」或功能区「排序」按钮（作用于当前分部）：

- 依据：**按数字**（千分位 / 百分号 / 全角数字都能识别）、**按文本**、
  **按填充颜色**（无填充排最前）、**按正则提取**（正则第一个捕获组作键，
  能转数字按数字比，如 `深度(\d+)`）
- 升序 / 降序；空值恒排最后；Ctrl+Z 可撤销

## 5. 筛选

右键「筛选…」（作用于当前分部，**只隐藏不删数据**）：

- 条件：等于 / 不等于 / 包含 / 不包含 / 开头是 / 大于 / 大于等于 /
  小于 / 小于等于（数字比较）/ **正则匹配** / 按填充颜色是
- 筛选后刷新、重算都保持；右键「清除筛选」一键恢复全部行

## 兼容性

数据文件格式不变，V2.5 以后的工程文件可直接打开；V2.9.2 全部功能保留。

附件 CalcBook-v2.10.0.exe（约 58MB），双击运行，免安装。
