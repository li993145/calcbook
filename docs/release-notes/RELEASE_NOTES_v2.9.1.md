# 工程量计算书 V2.9.1 更新说明

发布日期：2026-11-23

## 本次更新内容

1. **新增「单元格字体」设置（右键菜单）**
   选中单元格（单个 / 框选多格）后右键：
   - 「单元格字体…」：设置字体（系统字库）、字号（6–24）、加粗、斜体、下划线、删除线，对话框里实时预览；
   - 「单元格字体颜色…」：单独设置文字颜色；
   - 「清除单元格字体」：恢复默认字体与颜色。
   - 设置随工程文件保存，刷新、复制粘贴、撤销恢复（Ctrl+Z 一步撤回）都正常。
   - 不影响打印排版（打印仍按表格统一字体）。

2. **全角字符修正（解决导入后文字"全角、分散"）**
   原因：Excel / CSV 源表里常见全角数字、字母、标点（如 `１２３`、`（ｍ３）`）、
   全角空格，导入后原样进入计算书，显示又宽又散。
   处理：
   - 导入表格时自动把全角数字 / 字母 / 标点 / 空格转成半角并合并连续空格
     （`１２３（ｍ３）` → `123(m3)`、`挖　基坑` → `挖 基坑`），汉字不变；
   - 已导入的旧数据：选中单元格右键「选中单元格转半角（全角→半角）」一键修正，
     可 Ctrl+Z 撤销；
   - 公式列不转（公式里的全角括号是注释语法，转半角会改变计算语义）。
