# 工程量计算书 V3.4.0 发布说明

## 本次更新

1. **修复移动列后复制错列**：拖动表头调整列顺序后，复制多行多列数据不再错列。复制与粘贴统一按表头当前显示（视觉）顺序读写，与 WPS 表格一致。

2. **编号 / 单位 / 工程量默认居中**：这三列内容（含粘贴进来的数据）默认居中对齐；“不计”列仍默认居中，其余列默认靠左。仍可右键单独改对齐。

3. **修复剪切单元格误删整行**：框选某列多个单元格按剪切（Ctrl+X），现在只清空这些单元格内容，行和其他列数据完整保留；只有选中完整行时剪切才删除整行，整行复制/剪切后粘贴仍是“插入行、不覆盖”。

4. **取消「公式编辑」页签**：Ribbon 不再显示该页签，界面更简洁。所有内置函数功能完整保留——π、插入函数面板、round 四舍五入、向上取整、向下取整、sin、cos 放到标题栏左侧的快捷小按钮上；平方、立方等全部函数在“插入函数”面板里；F4–F7 插入括号快捷键照常可用。

5. **不再默认打开上次工程**：每次启动显示全新空白工程，保护隐私，也避免正在编辑时更新程序导致数据丢失。需要时请用「打开」「最近打开」或双击 `.gcls` 文件打开。
