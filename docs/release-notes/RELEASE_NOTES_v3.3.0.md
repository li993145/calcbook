# CalcBook V3.3.0 更新说明

发布日期：2026-11-23

## 本次改动

### 1. 复制 / 剪切 / 粘贴
- 选中整行（可多选）复制或剪切后，粘到表格任意位置会**插入行、原有数据顺延，不覆盖已有数据**。
- 右键「粘贴」不再局限于 WPS 数据：WPS / Excel、外部文件复制来的普通文本、本表内复制 / 剪切的数据（含字体、颜色、对齐、不计状态）都能贴。
- 在最后一行按**回车**自动追加新行；粘贴到末尾之外也自动补行（已核查并补上修改标记）。

### 2. 冻结窗格修正
- 鼠标停在冻结行 / 列上时滚动滚轮，整张表照常滚动，冻结区之外的数据正常显示（WPS 同款）。

### 3. 标题栏改版
- 恢复软件左上角程序图标（异瞳猫），去掉「新建 / 打开 / 保存 / 打印」四个小按钮；现在直接显示：
  软件图标 → 软件名称 + 版本号 → 工程文件名称 → **[文件绝对路径]**，路径标记从 `<>` 改成 `[]`。

### 4. 公式工具调整
- 取消「查看公式」「重算」按钮。
- 「公式编辑」页新增「常用函数」组：π、sin、cos、四舍五入、向上取整、向下取整、平方、立方。

### 5. 帮助文件
- 按 V3.3.0 界面与功能**重写《使用说明.txt》**，软件内「使用说明」同步更新。

## 继承
V3.2.0 及以前全部功能保留：冻结窗格设置、单元格 / 整行 / 整列 / 全表对齐、字体与颜色、格式刷、填充柄自动序号、排序筛选（数字 / 颜色 / 正则）、导入表格、全角转半角、新图标等。

## 兼容性
.gcls 数据文件格式不变，V2.5 以后工程可直接打开。
