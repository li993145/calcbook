# CalcBook V3.7.6 发布说明（内测）

> 本版本仅供内测，不上传 Gitee / GitHub。

## 新增 / 调整

### 1. 截图：形状选择 + 确认/退出工具条
- 拖出选区、**松开鼠标**后，选区旁弹出**浮动工具条**：
  - **矩形 / 椭圆**：选择截图形状，椭圆裁形四周透明（保存 PNG 保留）；
  - **确认截图**：确认选区，把图放进当前行图纸格（**双击选区**同样确认）；
  - **重新选择**：清掉当前选区重新框选（**点其他空白处**也可重新框选）；
  - **取消**：退出本次截图。
- Esc 随时退出、右键取消——不再只能按 Esc。

### 2. 工具栏精简（功能不丢，入口在导航栏 / 右键）
- 「插入计算式 / 添加计算式」「插入明细」「插入分部 / 添加分部」按钮取消——
  **导航栏右键**（新建下一级 / 新建同级 / 插入明细子目）已有这些功能；
- **F9 插入计算式快捷键保留**（改注册为窗口级快捷键）；
- 「选择图纸」按钮取消——单元格右键「图纸（当前行）→ 选择图片文件」仍可用；
- 「注释标签」按钮取消——移到**单元格右键「注释标签」**（弹标签子菜单插入备注）。

### 3. 明细子目 + 节点链接
- 导航栏右键**「插入明细子目」**：在当前节点下新建 `明细1 / 明细2 …` 节点
  （默认预置空计算式行，建完可**当场填链接**，也可留空稍后设置）；
- 右键**「设置链接…」**：给任意节点（单项/单位/分部/分项/明细子目）挂一个
  **网址或本地文件路径**（如 CAD 图、PDF、参考网页）；
- 挂了链接的节点名称后带 **[链]** 标记，悬停可看链接内容；
- 右键**「打开链接」**：用系统默认程序打开（本地路径走文件管理器，
  网址走默认浏览器，省略 `http://` 会自动补全）；
- 链接**随工程文件保存**；复制 / 打新节点时链接一起带上；可撤销。

## 修复
- 打开链接时 PyQt5 的 `QUrl` 误从 QtGui 导入会导致崩溃——已改从 QtCore 导入。
- 截图松开鼠标瞬间 `_show_toolbar` 引用已清空的拖拽坐标报错——已修复。
