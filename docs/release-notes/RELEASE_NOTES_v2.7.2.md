# 工程量计算书 CalcBook V2.7.2 发布说明

发布日期：2026-11-22
版本号：**V2.7.2**
标签：`v2.7.2`

---

## 一、本次更新概览

V2.7.2 增加右键自定义行高 / 列宽的能力，并修复「选中行高亮」按钮、新增「选中列高亮」。

## 二、新增与改进

### 1. 右键菜单自定义行高 / 列宽

- **行号右键** → 「设置本行行高…」：输入像素值（18–300）精确设置该行高度。
- **表头右键** → 「设置本列列宽…」：输入像素值（30–600）精确设置该列宽度，并同步到打印 / Excel 导出。
- **单元格右键** → 「设置选中行行高…」「设置选中列列宽…」：可框选多行 / 多列后统一设置。
- 手动设定后会自动关闭对应的「自动行高 / 自动列宽」模式，避免被自适应铺满覆盖；仍可随时用「自适应」恢复。

### 2. 修复「选中行高亮」并新增「选中列高亮」

**问题**：原「选中行高亮」按钮靠把选择模式切成「整行选择」来实现高亮，既不直观，还会破坏框选单元格删除、粘贴锚点等操作，看起来像「没启用」。

**改进**：改为**淡色底纹高亮**——当前行浅黄、当前列浅蓝、行列交叉（当前单元格）稍深的黄，**不改变选择模式**。两个功能做成可勾选按钮，按钮外观直接显示启用状态，设置会被记住。

## 三、验证

- 新增 24 项针对性测试（高亮开关 / 颜色 / 按钮同步、右键菜单项、行高列宽设置与写回、不改选择模式等），全部通过。
- 原有 V2.3 – V2.7 全部回归测试通过，无新增失败。
- 期间修复一处绘制崩溃：高亮改用绘制完成后的半透明色块叠加，不改动 QStyle 的内部绘制状态。
- exe 已重新打包，启动稳定、无崩溃日志。
