工程量计算书 CalcBook V3.7.5 使用说明
=====================================

一、启动与界面
--------------
1. 双击“工程量计算书.exe”即可运行，免安装、免 Python 环境、纯本地。
2. 软件图标 = 异瞳猫：出现在 exe 文件、窗口、任务栏；工程文件（.gcls）在资源
   管理器中显示独立的文件样式图标。exe 换目录后重新运行一次即自动重新关联。
3. 最上面是自绘标题栏：
   [橘黄底猫图标] 工程量计算书 V3.7.3 | 工程文件名 | [文件绝对路径]
   - 软件图标放在橘黄色圆角底上，左上角一眼可辨；标题栏不再显示常用函数
     快捷小按钮，也没有挪到其它位置（函数仍从“插入函数”入口调用）。
   - 未保存的工程路径显示 [未保存]；路径太长时中间省略，鼠标悬停可看全路径；
   - 空白处按住可拖动窗口，双击最大化/还原，最右是最小化/最大化/关闭按钮。
4. Ribbon 三个页签：
   - 计算书编辑：文件 / 编辑 / 层级 / 剪贴板 / 表格 / 选项 六组
       文件  ：新建、打开、保存、另存为、最近打开、备份目录、导入表格
       编辑  ：项目选项、插入计算式(F9)、添加计算式、插入明细、插入分部、
               添加分部、用分部打新
       层级  ：上移、下移、升级、降级、特殊字符、注释标签
       剪贴板：复制、剪切、删除、粘贴、恢复、撤销
       表格  ：查找替换、层级设置、表格字体、格式刷、排序、筛选、清除筛选
       选项  ：选项配置
   - 数据导出：查看报表 / 导出表格 / 数据汇总 / 打印 / 打印预览 / 页面设置
   - 关于产品：使用说明 / 关于产品
   注：“公式编辑”页签已取消，内置函数由“插入函数”面板和 F4–F7 快捷键调用（见第七节）。
5. 工作区：左侧导航栏（只显示节点名称，不再单列显示层级文字；内部“单项工程 →
   单位工程 → 分部工程 → 分项工程”层级照常，悬停节点可看层级名）+ 右侧计算
   表格；左下是常量框。导航栏、常量框都可用小箭头收起/展开，分隔线可拖动。
   分类汇总已改为弹窗：在单元格里右键 →“分类汇总…”即可弹出（汇总开着也能
   继续编辑表格）。
6. 状态栏右下角（WPS 式选区统计）：单选或多选“工程量”列的数据，立即显示
   “求和=… 平均值=… 计数=…”；不再显示固定的分部小计。选中整行时只统计其中的
   工程量；未选中工程量数据时该区为空。多选 / 全选后直接左键点某一格会恢复为
   只选这一格（WPS 同款），统计随之变为该格数据。
7. Ctrl + 鼠标滚轮：在表格上按住 Ctrl 滚动滚轮，单元格字号与手动行高/列宽按
   同比例放大缩小（6～24 号字），冻结区同步；不按 Ctrl 时滚轮照常滚动表格。

二、新建与录入
--------------
1. 点工具栏“新建”或按 Ctrl+N → 填写工程名称（必填）、建设单位、施工单位、
   设计单位、编制日期、备注 → 确定。修改工程信息：左侧树右键“工程信息设置”。
2. 左侧树右键可新建单项工程 / 下一级 / 同级、重命名、上移下移、升级降级、删除；
   层级名称可在“层级设置”里改成 标段 / 分部 等。
3. 默认列顺序：序号、编号、项目名称、单位、工程量、计算公式、图纸编号、大样图
   来源、不计、备注；默认宽度依次 80 / 135 / 340 / 80 / 100 / 600 / 150 /
   150 / 80 / 200。列宽默认固定，新增列 / 刷新表格不会打乱已调好的列宽；
   需要按内容铺满窗口时点快捷操作行的“列宽自适应”。工具栏“数据列定义”
   按钮已取消，表头右键仍可增删 / 重命名列、设置列宽。
   **序号列、以及新增的自定义列默认文本居中对齐**（见第四节）。
4. 在表格逐行填写（序号可手工填写，工程量由公式自动算出）；勾“不计”列后
   该行不参与汇总。
5. 单击只选中，Ctrl+C 直接复制；双击或 F2 才进入编辑。
6. 在最后一行按回车 → 自动追加新行并跳到该行。粘贴的数据超过末尾 → 自动加行。

三、复制 / 剪切 / 粘贴（WPS 同款）
----------------------------------
1. 选中单元格或框选区域，Ctrl+C 复制、Ctrl+X 剪切。Ctrl+C 复制的是选中矩形
   区域（TSV 文本，可直接粘到 WPS / Excel）；整行选中时还会带上完整格式。
   复制、粘贴都按表头“当前显示顺序”读写，拖动表头把列换位后也不会错列。
2. 右键“粘贴（WPS / 外部数据 / 本表复制剪切）”或 Ctrl+V，支持：
   - WPS / Excel 表格复制来的多行多列数据（Tab 分列、换行分行）；
   - 从外部文件、网页、记事本复制来的普通文本；
   - 本表内部复制/剪切的数据（含字体、颜色、对齐、不计状态等格式）。
3. **整行复制/剪切后粘到任意位置 = 插入行**：目标处原有数据顺延，
   不会被覆盖；剪切的数据插入后原位置已删除，相当于“移动行”。
   普通矩形区域复制粘贴则覆盖目标单元格，其他列不受影响。
   **只框选部分单元格（例如只选单位列几格）再剪切，仅清空这些单元格内容，
   不会删除整行**；只有选中完整行时剪切才会删除整行。
4. 以上操作均可 Ctrl+Z 一步撤销。Delete 清内容（不删行），Insert 在下方插行。

四、单元格格式
--------------
1. 对齐：单元格右键“单元格对齐”（靠左/居中/靠右/恢复默认）；行号右键
   “本行对齐”；列头右键“整列对齐”；左上角右键“全表对齐”。
   **序号、编号、单位、工程量以及新增列默认居中对齐**（粘贴进来的数据也
   居中）；其余默认靠左，“不计”列默认居中。对齐设置随工程保存，可撤销。
2. 字体：单元格右键“单元格字体…”（字体/字号/加粗/斜体/下划线/删除线，实时
   预览）、“单元格字体颜色…”、“清除单元格字体”。
3. 填充颜色：工具栏“格式”组“填充颜色/清除填充”，或右键“填充颜色…”，
   作用于单元格 / 整行 / 整列；优先级为 单元格 > 整行 > 整列。
4. 格式刷：选中源格 →“格式刷”（或右键），点/拖目标区域即可刷字体、底色、
   对齐；Esc 取消。
5. 全角转半角：导入时自动清洗；旧数据可单元格右键“转半角”或列头右键
   “整列转半角”（公式列跳过，公式里的全角括号是注释语法）。
6. 行高列宽：行号/列头/单元格右键或双击分隔线可调；“行高自适应”“列宽自适应”
   “恢复默认行高”在右键菜单里。

五、冻结窗格（锁定行/列，WPS 同款）
-----------------------------------
1. 右键行号 →“冻结至本行（含本行）”：向下滚动时该行及以上一直可见。
2. 右键列头 →“冻结至本列（含本列）”：向右滚动时该列及以左一直可见。
3. 可同时冻结行和列（先冻行再冻列），左上角交叉区一起锁定。
4. 鼠标停在冻结区上滚动滚轮，整张表照常滚动，冻结区外的数据正常显示。
5. 冻结区内的单元格可单击选中、双击原位编辑（编辑时镜像暂时让位）。
6. 左上角右键“取消全部冻结”；行号/列头菜单也有“取消冻结行/列”。
   冻结设置随工程保存，列宽/行高/筛选变化自动跟随。

六、拖动填充 / 排序 / 筛选
--------------------------
1. 填充柄：选中区域右下角蓝色小方块，按住向下/向右拖：
   纯数字等差（选两格可推断步长）、尾号数字进位（A-001→A-002，保留前导零）、
   文本循环复制、公式列整体复制；向上/向左递减。支持撤销。
2. 排序：右键“排序…”或工具栏“排序”——按数字/文本/填充颜色/正则提取，
   升序降序，空值殿后。
3. 筛选：右键“筛选…”或工具栏“筛选”——先选“筛选列”，再选条件（等于/
   不等于/包含/开头是/数字比较/正则/填充颜色）；V3.5 起窗口里选的列真正生效，
   只隐藏不删数据，编辑数据后结果立即重算；内容留空或正则写错会提示，不会
   “点了没反应”。V3.6 起筛选比较自动统一全角/半角与空格：单元格里的
   “Ａ－００１”用“A-001”也能筛到，数字比较与正则同样生效。
   取消筛选有三个入口：筛选窗口内的“清除筛选”按钮、工具栏
   “清除筛选”、右键“清除筛选”，点后全部行立即恢复显示。

七、公式写法与工具
------------------
1. 四则运算 + - * /，幂 ^（也支持 ² ³ 上标）；汉字、[]、{} 里的内容是注释，
   不参与计算；度分秒、√、π/pi 可直接参与运算。
2. 常量：@名称（如 @层高），左下常量框双击即可定义；不预置常量，需要钢筋
   单重时点“新建常量”旁的下拉“插入常用钢筋单重”。
3. 函数：abs、sqrt、sqr、round、ceil、floor、power(x,n)、sin、cos、tan、
   log、max、min、sum、avg、radians、du 等。
4. 内置函数：点快捷操作行的“插入函数”打开函数面板，点函数名即插入；平方
   sqr()、立方 power(x,3)、π/round/取整也都在函数面板里，点选即可。
5. F4 前置 ()、F5 插入 ()、F6 插入 []、F7 末尾 []，在表格直接打字时也生效。
6. 公式辅助输入框与公式单元格实时双向同步：单元格逐字输入时辅助框同步显示，
   在辅助框输入时单元格和工程量实时更新；数字红、运算符黑、注释绿。
   Ctrl+Enter 确认公式。
7. 特殊符号面板：“计算书编辑 → 特殊符号”，含 × ÷ π ² ³ @ ± ° ′ ″ ∠ ⊥
   √ 等，点一下插入到当前输入位置，可连续点选。
   钢筋等级用 TssdEng（探索者）字体的国标制图符号：一级 HPB300、二级
   HRB335、三级 HRB400、四级 HRB500，点按钮即插入公式；字体随软件附带，
   本机没装 tssdeng 字体时这一组会自动隐藏。写在公式开头的钢筋规格不参与
   计算，旧写法 Φ / Φ² / Φ³ / Φ⁴ 仍兼容。

八、导入表格文件
----------------
“计算书编辑 → 导入表格”，支持 .xlsx / .csv / .txt：
选文件 → 选工作表/表头/起始行 → 预览 → 逐列指定写入字段 → 指定写入行
（追加到末尾或从指定行覆盖）。行数不足自动补行，导入自动清洗全角字符，
整次导入可 Ctrl+Z 撤销。

九、打印与导出
--------------
1. Ctrl+P 连系统打印机（可选“Microsoft Print to PDF”存 PDF）；每页重复
   报表标题和表头。打印预览支持拖动蓝色虚线调页边距，与实际打印一致。
2. 页面设置：表头标题、页眉、页脚左/中/右、页边距、纸张方向/大小、对齐方式；
   每页底部自动“第 X 页，共 Y 页”。
3. 打印区域：选中部分单元格后右键“设置打印区域”，打印/小计只算选中部分；
   “清除打印区域”恢复全部。
4. 导出 Excel / WPS 表格（.xlsx）：所有计算书、分部、格式一次导出。

     快速启动（自动打开上次编辑工程、记住上次关闭窗口大小及位置）、

【V3.7.5 新增与修正】
   - 【单元格内换行】编辑单元格时按 Alt+Enter 在光标处插入换行，单元格内
     多行显示、行高自动撑高（工程量/单位/不计/图纸列除外）；普通回车仍是
     “确定并移动光标”。

     ①区域截图（Ribbon“编辑”旁新增“图纸”组→“图纸截图”，或右键图纸列→

   - 【右侧图纸预览面板】工作区最右侧显示当前行的图纸，随选中行联动；

     自动补到“计算公式”后面，原数据不丢。

【V3.7.4 新增与修正】
   - 【默认就有一片可输入的空行区】新建工程 / 新建分部时，表格自动预置 15 行
     空计算式（个数可在“选项配置 → 分部 → 默认计算式个数”调整），打开就能

     升级为 15（自己改过个数的保持不变）。
   - 【分部打断】把光标点到表格某一行，右键“在此行打断分部”（或 Ribbon
     “编辑”组的“分部打断”）：本行起以下各行归入紧随其后的新分部，名称可改、
     重名自动加序号，打断后自动切到新分部继续填写；不用再去项目结构窗口
     新建节点、手动搬数据。Ctrl+Z 可撤销。
   - 【项目结构树行距收紧】左侧导航节点行高按名称字体实际高度显示，
     一屏能看到更多节点。
   - 【全选角右键菜单修好并加强】以前表格左上角（全选钮）右键经常毫无反应
     （角标按钮由 Qt 延迟创建，旧连接丢失）；现已修好，且菜单里补上复制 /
     剪切 / 粘贴 / 清除内容 / 删除选中行 / 填充颜色等单元格操作；冻结区里
     右键同样能弹出单元格菜单。
   - 【冻结窗格修复】以前只要编辑过一次单元格，冻结的行/列就消失不再显示
     （编辑结束信号接错了对象，镜像再也不恢复）；已修复，滚动时冻结线以上/
     以左部分始终固定，以下/以右部分随鼠标滚动；行高变化也会同步到冻结区。
   - 【函数面板调整】“插入函数”面板：幂运算 power 取消（幂直接写 2^3 即可），
     改为立方 cube（cube(3)=27，也可写 3³ 或 3^3）；常量 π 挪到面板最上方的
     “常量”分组（面板左上角一眼可见）。
