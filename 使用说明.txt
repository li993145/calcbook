工程量计算书 CalcBook V3.4.0 使用说明
=====================================

一、启动与界面
--------------
1. 双击“工程量计算书.exe”即可运行，免安装、免 Python 环境、纯本地。
2. 软件图标 = 异瞳猫：出现在 exe 文件、窗口、任务栏；工程文件（.gcls）在资源
   管理器中显示独立的文件样式图标。exe 换目录后重新运行一次即自动重新关联。
3. 最上面是自绘标题栏：
   [π ƒ R ↑ ↓ S C] [猫图标] 工程量计算书 V3.4.0 | 工程文件名 | [文件绝对路径]
   - 左端一排常用函数快捷小按钮：π（圆周率）、ƒ（插入函数面板）、R（四舍五入
     round）、↑（向上取整 ceil）、↓（向下取整 floor）、sin、cos；
     点一下就把对应函数插入当前公式（和 WPS 表格的工具按钮一样）。
   - 未保存的工程路径显示 [未保存]；路径太长时中间省略，鼠标悬停可看全路径；
   - 空白处按住可拖动窗口，双击最大化/还原，最右是最小化/最大化/关闭按钮。
4. Ribbon 三个页签：
   - 计算书编辑：文件 / 编辑 / 格式 / 计算书（导入表格、分类汇总、格式刷、排序、筛选等）
   - 数据输出：导出 Excel / 导出 WPS / 打印 / 打印预览 / 页面设置
   - 关于产品：使用说明 / 关于产品
   注：“公式编辑”页签已取消，所有内置函数改由标题栏快捷按钮和“插入函数”面板
   调用（见第七节）。
5. 工作区：左侧导航树（单项工程 → 单位工程 → 分部工程 → 分项工程，可自定义层级
   名称）+ 中间计算表格 + 右侧分类汇总面板；左下是常量框。
   导航栏、汇总面板、常量框都可用小箭头收起/展开，分隔线可拖动。

二、新建与录入
--------------
1. 点工具栏“新建”或按 Ctrl+N → 填写工程名称（必填）、建设单位、施工单位、
   设计单位、编制日期、备注 → 确定。修改工程信息：左侧树右键“工程信息设置”。
2. 左侧树右键可新建单项工程 / 下一级 / 同级、重命名、上移下移、升级降级、删除；
   层级名称可在“层级设置”里改成 标段 / 分部 等。
3. 在表格逐行填写 编号、项目名称、部位、计算公式、单位、备注；公式写完工程量
   自动算出，每个分部自动“小计”；勾“不计”列后该行不参与汇总。
4. 单击只选中，Ctrl+C 直接复制；双击或 F2 才进入编辑。
5. 在最后一行按回车 → 自动追加新行并跳到该行。粘贴的数据超过末尾 → 自动加行。

三、复制 / 剪切 / 粘贴（WPS 同款）
----------------------------------
1. 选中单元格或框选区域，Ctrl+C 复制、Ctrl+X 剪切。Ctrl+C 复制的是选中矩形
   区域（TSV 文本，可直接粘到 WPS / Excel）；整行选中时还会带上完整格式。
   复制、粘贴都按表头“当前显示顺序”读写，拖动表头把列换位后也不会错列。
2. 右键“粘贴（WPS / 外部数据 / 本表复制剪切）”或 Ctrl+V，支持：
   - WPS / Excel 表格复制来的多行多列数据（Tab 分列、换行分行）；
   - 从外部文件、网页、记事本复制来的普通文本；
   - 本表内部复制/剪切的数据（含字体、颜色、对齐、不计状态等格式）。
3. **整行复制/剪切后粘到任意位置 = 插入行**：目标处原有数据顺延，
   不会被覆盖；剪切的数据插入后原位置已删除，相当于“移动行”。
   普通矩形区域复制粘贴则覆盖目标单元格，其他列不受影响。
   **只框选部分单元格（例如只选单位列几格）再剪切，仅清空这些单元格内容，
   不会删除整行**；只有选中完整行时剪切才会删除整行。
4. 以上操作均可 Ctrl+Z 一步撤销。Delete 清内容（不删行），Insert 在下方插行。

四、单元格格式
--------------
1. 对齐：单元格右键“单元格对齐”（靠左/居中/靠右/恢复默认）；行号右键
   “本行对齐”；列头右键“整列对齐”；左上角右键“全表对齐”。
   **编号、单位、工程量三列默认居中对齐**（粘贴进来的数据也居中）；其余
   默认靠左，“不计”列默认居中。对齐设置随工程保存，可撤销。
2. 字体：单元格右键“单元格字体…”（字体/字号/加粗/斜体/下划线/删除线，实时
   预览）、“单元格字体颜色…”、“清除单元格字体”。
3. 填充颜色：工具栏“格式”组“填充颜色/清除填充”，或右键“填充颜色…”，
   作用于单元格 / 整行 / 整列；优先级为 单元格 > 整行 > 整列。
4. 格式刷：选中源格 →“格式刷”（或右键），点/拖目标区域即可刷字体、底色、
   对齐；Esc 取消。
5. 全角转半角：导入时自动清洗；旧数据可单元格右键“转半角”或列头右键
   “整列转半角”（公式列跳过，公式里的全角括号是注释语法）。
6. 行高列宽：行号/列头/单元格右键或双击分隔线可调；“行高自适应”“列宽自适应”
   “恢复默认行高”在右键菜单里。

五、冻结窗格（锁定行/列，WPS 同款）
-----------------------------------
1. 右键行号 →“冻结至本行（含本行）”：向下滚动时该行及以上一直可见。
2. 右键列头 →“冻结至本列（含本列）”：向右滚动时该列及以左一直可见。
3. 可同时冻结行和列（先冻行再冻列），左上角交叉区一起锁定。
4. 鼠标停在冻结区上滚动滚轮，整张表照常滚动，冻结区外的数据正常显示。
5. 冻结区内的单元格可单击选中、双击原位编辑（编辑时镜像暂时让位）。
6. 左上角右键“取消全部冻结”；行号/列头菜单也有“取消冻结行/列”。
   冻结设置随工程保存，列宽/行高/筛选变化自动跟随。

六、拖动填充 / 排序 / 筛选
--------------------------
1. 填充柄：选中区域右下角蓝色小方块，按住向下/向右拖：
   纯数字等差（选两格可推断步长）、尾号数字进位（A-001→A-002，保留前导零）、
   文本循环复制、公式列整体复制；向上/向左递减。支持撤销。
2. 排序：右键“排序…”或工具栏“排序”——按数字/文本/填充颜色/正则提取，
   升序降序，空值殿后。
3. 筛选：右键“筛选…”——等于/不等于/包含/开头是/数字比较/正则/填充颜色；
   只隐藏不删数据，“清除筛选”一键恢复。

七、公式写法与工具
------------------
1. 四则运算 + - * /，幂 ^（也支持 ² ³ 上标）；汉字、[]、{} 里的内容是注释，
   不参与计算；度分秒、√、π/pi 可直接参与运算。
2. 常量：@名称（如 @层高），左下常量框双击即可定义；不预置常量，需要钢筋
   单重时点“新建常量”旁的下拉“插入常用钢筋单重”。
3. 函数：abs、sqrt、sqr、round、ceil、floor、power(x,n)、sin、cos、tan、
   log、max、min、sum、avg、radians、du 等。
4. 内置函数：点标题栏左端的 ƒ（插入函数）按钮打开函数面板，点函数名即插入；
   常用函数也可直接点标题栏快捷按钮：π、round（四舍五入）、↑ 向上取整、
   ↓ 向下取整、sin、cos。平方 sqr()、立方 power(x,3) 在函数面板里。
5. F4 前置 ()、F5 插入 ()、F6 插入 []、F7 末尾 []，在表格直接打字时也生效。
6. 公式辅助输入框与公式单元格实时双向同步：单元格逐字输入时辅助框同步显示，
   在辅助框输入时单元格和工程量实时更新；数字红、运算符黑、注释绿。
   Ctrl+Enter 确认公式。
7. 特殊符号面板：“计算书编辑 → 特殊符号”，含 × ÷ π ² ³ @ ± ° ′ ″ ∠ ⊥
   Φ/Φ²/Φ³/Φ⁴ √ 等，点一下插入到当前输入位置，可连续点选。

八、导入表格文件
----------------
“计算书编辑 → 导入表格”，支持 .xlsx / .csv / .txt：
选文件 → 选工作表/表头/起始行 → 预览 → 逐列指定写入字段 → 指定写入行
（追加到末尾或从指定行覆盖）。行数不足自动补行，导入自动清洗全角字符，
整次导入可 Ctrl+Z 撤销。

九、打印与导出
--------------
1. Ctrl+P 连系统打印机（可选“Microsoft Print to PDF”存 PDF）；每页重复
   报表标题和表头。打印预览支持拖动蓝色虚线调页边距，与实际打印一致。
2. 页面设置：表头标题、页眉、页脚左/中/右、页边距、纸张方向/大小、对齐方式；
   每页底部自动“第 X 页，共 Y 页”。
3. 打印区域：选中部分单元格后右键“设置打印区域”，打印/小计只算选中部分；
   “清除打印区域”恢复全部。
4. 导出 Excel / WPS 表格（.xlsx）：所有计算书、分部、格式一次导出。

十、其他
--------
1. 右侧分类汇总：按编号/项目名称/部位/分部/单位分类合计，支持多条件，
   可导出 Excel 或复制粘贴到 WPS。
2. 自动保存：“选项配置”可设开关、间隔、备份目录；**启动不再自动打开上次
   工程**——每次打开都是空白工程（保护隐私、避免更新程序时误改/丢失正在编辑
   的数据），需要时从“最近打开”或双击 .gcls 文件打开。
3. 工程文件为 .gcls（JSON 文本），兼容 V2.5 以后所有版本；旧 .json 也能打开。
4. 常用快捷键：Ctrl+N 新建、Ctrl+O 打开、Ctrl+S 保存、Ctrl+P 打印、
   Ctrl+F 查找、Ctrl+C/X/V 复制/剪切/粘贴、Ctrl+Z/Y 撤销/恢复、
   Delete 清内容、Insert 插行、F2 编辑、F4–F7 括号、Ctrl+Enter 确认公式、
   末行回车加新行。
