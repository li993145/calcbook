工程量计算书 V2.5.0 使用说明
================================

【启动】
双击 dist 目录下的"工程量计算书.exe"即可，无需安装、无需 Python 环境。
程序图标为山水图（月亮与瀑布那张），与兔兔计算书（红色兔子）区别。

【软件图标与工程文件图标】（V2.5）
- 软件图标：窗口左上角、任务栏、桌面快捷方式都显示山水图标。
- 工程文件图标：第一次运行 exe 会自动把 .gcls 关联到本程序，资源管理器里
  工程文件就显示成同一个山水图标，双击文件即用本程序打开。
- 如果移动了 exe 的位置（图标变回白纸/旧图标），重新运行一次 exe 即可自动重新关联；
  资源管理器按 F5 刷新即可看到新图标。

【最上面那条标题栏】（自绘标题栏，取代 Windows 系统标题栏）
- 窗口最上面就是本程序自己的标题栏（不再有 Windows 系统标题栏那一层），
  左端一排小图标＝新建 / 打开 / 保存 / 打印，紧跟着是信息块：
  软件图标 → “工程量计算书 V2.5.0” → 工程文件名称 → <文件存放详细地址>，
  例如：工程量计算书 V2.5.0 | 燕儿窝油库.gcls | <D:\工程\燕儿窝油库.gcls>。
  最右边是 最小化 / 最大化 / 关闭 三个按钮。
- 标题栏里不再显示工程名（“某某项目”只在任务栏的窗口标题上）。
- 标题栏空白处按住可拖动窗口，双击可最大化/还原；鼠标移到窗口边缘可拖拽调整大小。
- 还没保存的新工程显示 <未保存>；路径太长时中间用省略号，鼠标停在上面可看全路径。

【基本流程】（和兔兔一致）
1. 新建工程：点工具栏"新建"，弹出"新建工程"对话框，一次填好
   工程名称、建设单位、施工单位、设计单位、编制日期、备注（只有工程名称必填）；
   确定后即创建新工程，工程名称同时用于报表表头。
   建好后想改工程信息：左侧树里右键 →"工程信息设置…"
2. 新建计算书：左侧树右键 →"新建计算书"，一个工程可包含多本计算书
3. 新建分部：在左侧树里右键 →"新建分部"或"新建子分部"，可多级嵌套
4. 录入数据：在表格中逐行填写 编号、项目名称、部位、计算公式、单位、备注
   - 公式写完自动计算工程量；每个分部自动汇总"小计"
5. 导出：点"导出Excel"，生成 .xlsx 文件，WPS 表格可直接打开（含所有计算书）

【多计算书】
- 左侧树中每个顶级节点（📖图标）就是一本计算书，可有多本
- 右键计算书节点：新建计算书 / 重命名计算书 / 删除计算书 / 新建分部
- 点击不同计算书即可切换编辑，各自的分部树和工程量独立
- 保存/打开/导出自动包含所有计算书；旧版单计算书工程可正常打开

【公式写法】
- 四则运算：+ - × ÷（或 * /），幂运算用 ^，例：2^3、4×9.6×0.1
- 注释：公式里的汉字、[方括号]、{花括号}内容自动忽略，不参与计算
  例：4×9.6[柱基预埋] 只计算 4×9.6
- 常量：@加名称，如 @层高，全工程通用（左下"常量"框显示，双击可编辑）
- 常量全部自己定义（V2.4 起不再预置）；需要钢筋单重时点"▾"→"插入常用钢筋单重"，
  会插入 @Φ6=0.222、@Φ8=0.395、@Φ10=0.617 … @Φ40=9.87（kg/m），
  公式里直接写 @Φ8×12 即 Φ8 钢筋 12m 的重量（4.74kg）；也可写 12×@Φ8
- 函数：ceil、floor、sqr、sqrt、round、power(x,n)、pi、radians、
  Du、abs、max、min、sum、sin、cos、tan
- 点快捷栏/工具栏"插入函数"弹出函数面板，点函数名即插入"函数名()"，
  光标停在括号内；每个函数都有写法提示（鼠标停一下可看）
- 汇总：XJ() 自动汇总当前分部下所有子分部的工程量
- 度分秒：34°56′30″ 直接参与计算；π 或 pi 可直接用，如 π×3^2
- 开平方：√ 直接参与运算，√9=3、√(3+4)、2×√9=6、√(9+√16) 均可（也可写 sqrt(9)）
- 钢筋规格写在公式开头不参与计算：3Φ³8@200 4×5 = 20（Φ、Φ²/Φ³/Φ⁴ 当注释）
- 上标幂：支持 ² ³ 直接当乘方，如 3³=27、5²=25
- 不计：勾选"不计"列的复选框后，该行不参与汇总（工程量仍显示）

【公式辅助输入框】（V1.5 真正双向实时同步）
- 只在"计算公式"列生效：选中公式列单元格时，公式同步显示在上方辅助框
- 单元格 → 辅助框：在表格公式单元格里【每敲一个字符】，辅助框立即同步显示，
  无需等回车/失焦（通过单元格编辑器逐字同步）
- 辅助框 → 单元格：在辅助框里输入，下方单元格、正在编辑的编辑器、
  工程量结果全部实时更新；两边内容始终一致，不会互相覆盖
- 着色：数字红色、运算符黑色、备注汉字淡绿色、上标蓝色
- Ctrl+Enter 或点"写入"确认；也可直接输入，无需额外操作

【F4-F7 括号快捷键】
- F4：在公式最前面插入 ()
- F5：在光标插入点插入 ()
- F6：在光标插入点插入 []
- F7：在公式末尾追加 []
- 这四个键在表格"计算公式"单元格里直接打字时也生效（插入到光标处）
- [] 内写的文字按备注处理、不参与计算，如 4×9.6[柱基]
- 快捷操作链接行里也有对应按钮

【特殊符号面板】（V2.0：菜单栏下方的符号栏已取消，统一用面板）
- 点工具栏"编辑2"组"特殊符号"，弹出符号面板：
  × ÷ π ² ³ @ ± ㎡ ≤ ≥ ° ′ ″ ∠ ⊥ Φ Φ² Φ³ Φ⁴ √ D R 全部可选
- 钢筋等级按建筑行业习惯：一级 Φ(HPB300)、二级 Φ²(HRB335)、
  三级 Φ³(HRB400)、四级 Φ⁴(HRB500)——Φ 右上角数字表示级别；
  面板里用标准图纸图形（圆圈+竖线，二/三/四级依次在下方加 1/2/3 条横线）
  显示，看着选不会认错
- 点一下插入到当前输入位置（正在编辑的单元格光标处 / 公式辅助框光标处 /
  当前单元格末尾）；面板点符号后不关闭，可连续插入多个

【表格右键】（V2.3 补齐行号右键）
- 单元格右键：在上方插入行 / 在下方插入行 / 删除选中行 / 粘贴WPS数据 /
  列宽自适应 / 行高自适应 / 恢复默认行高 / 标记为不计
- "不计"列：勾选框画在单元格正中，点格内任意位置即可切换（空格键也行）
- 行号（表格最左侧数字）右键：在上方插入行 / 在下方插入行 / 在末尾追加行 /
  删除本行 / 本行底色（黄/绿/蓝/粉/灰，或"其他颜色…"、清除本行底色）/
  本行行高自适应 / 全部行高自适应 / 全部列宽自适应
- 表头右键：在左侧添加列 / 在右侧添加列 / 整列填充颜色 / 清除整列填充 /
  本列列宽自适应 / 重命名列 / 删除列
- 表格左上角（全选角）右键：删除当前单项工程的全部数据 / 删除全部数据 /
  自动行高 / 自动列宽（可勾选切换）/ 列宽自适应 / 行高自适应 /
  列宽+行高全部自适应 / 恢复默认行高 / 全选表格
- 键盘：Insert 在下方插行，Delete 删除行，Ctrl+C/X/V 复制/剪切/粘贴行

【目录树（单项工程 / 单位工程 / 分部工程 / 分项工程）】（V2.5 重做）
- 树有两列："名称"和"层级"；第一级固定是"单项工程"（默认"单项工程1"，
  不可删除），往下依次是单位工程 / 分部工程 / 分项工程，可以继续往下加，
  超过四级时沿用最后一级的名称
- 工具栏"层级设置"：可改名、增删层级（如改成 标段 / 单位工程 / 分部 / 分项），
  新建节点会自动使用下一级的名称（如"单位工程1""分部工程2"）
- 树右键：新建单项工程 / 新建下一级 / 新建同级 / 重命名 / 上移 / 下移 /
  升级（提上一层）/ 降级（挂到上一个下面）/ 删除 / 层级设置 / 工程信息
- 右键会先选中该节点；不能做的那一项会变成灰色（例如同级只有一个时的上移）
- 删除只影响该节点及其下级，不会误删上级或同级；删除后可用 Ctrl+Z 撤销
- 工具栏"上移/下移/升级/降级"作用于当前选中的节点；单项工程也能上移下移调整顺序

【自动保存 + 备份目录】
- 工具栏"计算书"组点"选项配置"——自动保存开关、间隔、备份目录都在这里设
- 可开启/关闭、设置间隔（1-120分钟）、指定备份目录
- 到点时若工程有改动：自动写回主文件；若设了备份目录，
  同时在该目录生成带时间戳的备份副本（如"工程名-自动备份-20261122-153000.gcls"）
- 设置了备份目录后，即使工程还没另存为文件也能自动备份

【撤销 / 恢复】（V2.5 修复）
- Ctrl+Z 撤销、Ctrl+Y 恢复（工具栏"编辑3"组的"撤销/恢复"同）
- 逐字输入公式只算"一步"（改前状态在进入编辑时记下），撤销回到输入前
- 支持：公式/编号/名称/单位/备注编辑、插入删除行、粘贴、填充色、不计勾选、
  新建/重命名/删除/上移/下移/升级/降级、删除全部数据、改常量、改层级、列增删
- 连续改常量框（1.2 秒内）合并为一步，不会一步一个字

【查找】（V2.5 修复）
- 工具栏"查找"或 Ctrl+F 打开查找面板
- 查找范围可选：全部字段（自定义关键词）/ 编号 / 项目名称 / 单位 / 部位 /
  计算公式 / 备注
- 范围可选"全部单项工程"或"当前分部（含下级）"
- 输入关键词后按回车或点"下一个"逐个定位：自动切到对应分部、选中该行单元格
- 面板上显示"第 n / N 个匹配"，可循环查找

【数据输出】（V1.9：新增“打印”，连系统打印机）
- 导出Excel表格：生成 .xlsx，Excel 打开
- 导出WPS表格：生成 .xlsx（WPS 表格原生支持），导出后可直接用 WPS 打开、
  另存为 .et
- 打印（Ctrl+P）：调出系统打印对话框，可选打印机、份数、页码范围，
  按“页面设置”里的纸张方向/四边页边距输出，直接打印到打印机或
  选“Microsoft Print to PDF / 导出为WPS PDF”存成 PDF
- 打印预览：切到报表页，按纸张实际比例分页显示；把鼠标移到页面上的
  蓝色虚线上（光标变左右/上下箭头），按住拖动即可调整页边距，上方四个
  数值框同步更新；也可在数值框里直接输入。改动会立即保存并用于打印/导出
- 页面设置：表头标题、页眉、页脚左/中/右三栏（签字栏）、上/下/左/右页边距(cm)、
  纸张方向(纵向/横向)、纸张大小（下拉列出系统打印机支持的纸型，如 A4/A3/A5/B5/Letter…，
  选"自定义"可自己输入宽高 mm）、水平对齐、垂直对齐
- 打印预览顶部显示当前纸张（如"纸张：A4 210×297mm（纵向）"）
- V2.5：打印与预览每一页都会重复"报表标题 + 表头行"（列名），翻到第 2 页
  也能看到每一列的名称，不会出现"第 2 页开始只有数据没有表头"的情况；
  预览里的分页与实际打印完全一致（页数、每页行数都相同）
- V2.8：页脚左/中/右三栏可填编制人、复核人、日期等；打印和预览每页中间自动显示
  "第 X 页，共 Y 页"，无需手动填页码；导出 Excel 时也写入三栏页脚与自动页码
- 打印选中区域：框选单元格后点"设置打印区域"，报表只输出选中的行列；
  点"清除打印区域"恢复打印整张计算书

【单位列与小数位】（V2.2 新增）
- 单元格里点单位列任意一格，会弹出常用工程计量单位下拉框：
  m、m2、m3、kg、t、个、块、套、处、台、组、根、樘、座、件、项、
  台班、延长米、千块……（可滚动选择，也可直接输入自定义单位）
- 工程量小数位按单位自动决定，不用再手动设精度：
    m / m2 / m3 / kg             → 2 位小数
    t（吨）                      → 3 位小数
    个 / 块 / 套 / 处 / 台 / 组   → 取整（四舍五入）
    其他单位                     → 默认 3 位
- 改单位后该行工程量立即按新位数显示；小计按该分部所需的最多位数显示
- 表格、打印预览、打印、导出的 Excel 全部按同一规则，不会再出现
  "12个" 写成 "12.000个" 这种情况

【常量框（三列，全部自定义）】（V2.4 重做）
- 常量框三列：常量代码 / 值 / 说明，与兔兔一致；双击任一单元格即可修改
  （代码不写 @ 会自动补上），说明只作备注不参与计算
- 上方："ab 新建常量"、"✕ 删除"、"⇩ 导出常量"（导出 CSV，可用 WPS 打开）
- 点"▾"更多：批量编辑 / 粘贴常量、插入常用钢筋单重模板、清空全部常量
- 导航树与常量框之间有分隔条，按住上下拖动即可调整常量框高度（行高自动适配）
  （关软件时记住高度，下次启动沿用）
- 新建工程不再预置任何常量（V2.4 起）；需要钢筋单重时点"▾"→
  "插入常用钢筋单重（14 条模板）"，插入后可随意改值/改名/删除：
    @Φ6=0.222  @Φ8=0.395   @Φ10=0.617  @Φ12=0.888
    @Φ14=1.21  @Φ16=1.58   @Φ18=2      @Φ20=2.47
    @Φ22=2.98  @Φ25=3.85   @Φ28=4.83   @Φ32=6.31
    @Φ36=7.99  @Φ40=9.87
- 用法：单位选 kg，公式写 12×@Φ8 → 4.74（kg）；单位选 t 则换算后写 /1000
- 行高：常量框每行至少 24px（V2.5 加大行距），行多时出现竖向滚动条，
  点"新建常量"会自动滚动到新行并进入编辑
- 常量改动后公式自动重算；公式里引用了没定义的常量，该行会红色提示
  "未定义的常量：@xxx"，到常量框新增一条即可
- 导出的 Excel 里也会多一张"常量表"工作表，列出全部常量

【面板收起 / 展开】（V2.4 新增）
- 左侧导航右边、常量框上方、右侧汇总面板左边各有分割条，条上两个小箭头：
  例如导航条上"◀"收起、"▶"展开；常量条上"▾"收起、"▴"展开；
  汇总条上"▶"收起、"◀"展开
- 收起后表格区域自动变大，再点展开即恢复原来的宽度 / 高度（软件会记住）

【列宽 / 行高】默认自适应（V2.5 起不用手点）
- 列宽：按表头和单元格内容算宽度，并把剩余宽度给"计算公式"列，让表格铺满窗口；
  内容比窗口宽时优先压缩名称/备注/部位，尽量不出横向滚动条
- 行高：按内容自动撑高（长公式/备注换行完整显示），不用再点"行高自适应"
- 手动拖动过列宽后，自动列宽会关闭（避免被抢回去）；在表格左上角角标右键
  重新勾选"自动列宽 / 自动行高"即可恢复
- 仍可手动：列宽自适应（按内容，写入列定义）/ 行高自适应 / 恢复默认行高
- 行高自适应：长公式、长备注、长项目名称自动换行并撑高行，
  完整显示不截断（单行最高 200px）；"恢复默认行高"回到 34px 不换行
- 入口：表格左上角角标右键、行号右键、单元格右键、表头右键；
  也可直接把鼠标移到两列（或两行）表头之间的分隔线上双击，即自适应该列/该行
  （与 WPS / Excel 的操作习惯一致）

【填充颜色】（V2.1 新增）
- 工具栏"格式"组"填充颜色"：选颜色 + 选范围（整行 / 整列 / 仅选中单元格）
- 先选中要着色的单元格（或整行/整列），点"填充颜色"，选颜色再点"确定"
- 优先级：单元格 > 整行 > 整列（单元格色覆盖行色）
- "清除填充"按当前选择自动判断清除范围；表头右键可整列着色/清除
- 颜色会同步出现在打印预览、打印和导出的 Excel 里

【其他功能】（仿兔兔）
- 分类汇总（V2.4）：右侧面板可按 编号 / 项目名称 / 部位 / 分部 / 单位 合计，
  同名同单位的多行自动累加；勾"仅当前分部"只统计左侧选中分部；
  "刷新"重算、"导出"存 Excel、"复制"可直接粘到 WPS
- 汇总表操作（V2.8）：单元格可多选、Ctrl+C 复制选中区域；所有列宽均可直接拖动
  （含项目名称列）并自动记住；表头/角标/单元格右键可设置列宽/行高、自适应、
  复制整表、导出；标题行"⤢"按钮可隐藏主工作区、放大查看汇总，"⤡"还原
- 导出数字：把所有工程量以纯数字复制到剪贴板
- 人民币转换：把选中行工程量转为人民币大写写入备注
- 查看公式：列出当前分部所有公式
- 树形显示：展开/折叠全部节点；选中列高亮：给当前列加淡色底纹
- 数据列定义：集中管理列名、宽度、增删列

【工程文件】（V2.1 起后缀为 .gcls）
"保存"生成 .gcls 工程文件（内容仍是 JSON 文本，便于排查），包含所有计算书、
分部结构、公式、备注、常量、列定义、填充色与页面设置；可随时"打开"继续编辑。
旧版 .json 工程也能直接打开（打开对话框里同时列出 .gcls 与 .json）。建议定期备份。
标题栏左端显示"软件图标 + 软件名版本 + 工程文件名称 + 文件存放地址"，不再显示
文件名以外的工程名（V2.5 起不重复显示文件名与后缀）；保存时若工程名称还是"未命名工程"，
会自动用文件名作为工程名称。软件启动时自动打开上次保存/打开的工程。

【与兔兔的区别】
- 纯本地单文件，不联网、不弹断言错误、不依赖加密锁
- 导出真正的 .xlsx，WPS/Excel 都能打开
- 绿色兔子图标，与兔兔计算书区分
